# CaaS 2.6.1 快速开始

1. 将交付 ZIP 完整解压到本地文件夹。
2. 打开 `CaaS-Setup-x64.exe` 安装，或直接打开 `CaaS-Portable-x64.exe`。只需选一种，无需 Node.js 或数据库服务。
3. 升级时先正常退出旧版，再打开新版；旧数据自动沿用，不要删除数据库。
4. 按 `F11` 全屏；顶部“≡”折叠或展开导航。总览向下滚动查看租赁收入、Token 生产、模型排行与资源洞察；曲线提示暂停时，点击“恢复更新”。
5. 按 `Ctrl+Shift+M` 打开后台，首次自行设置密码。内容修改后点击“保存并应用”。
6. 换电脑前，在后台“导出内容包”；目标电脑使用自己的密码导入内容包。

`Ctrl+Shift+D` 可显示或收起操作面板。顶部是当前北京时间，底部“数据时间”是本地业务时钟；暂停、维护、预览期间业务时钟冻结。

数据位于 `%APPDATA%\CaaSDesktop\data\caas.sqlite`。安装版和便携版共用同一用户的数据，复制程序不会复制当前内容。没有通用默认管理员密码。

本版交付范围是离线桌面展示与本地管理，算力、设备、遥测、推理和计费为本地模拟；具体功能、验证环境与限制见《使用说明》和《实际测试记录》。

Token 设置：后台 → Token 生成设置，修改固定 / 波动模式、速率倍率与幅度，再“保存并应用”。当日及累计数字每秒增长，精确值显示在紧凑数值下方。关闭和休眠期间停止产出；正常退出保存最新进度，意外中断最多回退约 5 秒。

## 租赁与模型用量

侧栏「算力租赁数据」可按日、周、月、年查看租金和八张图表。总览 Token 区可切换当日 / 累计模型用量。新产品需要在后台「产品目录」填写实际月价后，使用匹配 GPU 型号与卡数的节点编排租赁；X1 仅产 Token。详见《租赁与模型用量说明》。

# 2.6.1 算力租赁与模型用量

2026-10-23。新增导航「算力租赁数据」，总览增加租金统计与图表，Token 区增加模型用量排行榜。

## 租金统计

- 日、周、月、年分别从北京时间当日零点、周一零点、当月一日及当年一月一日累计。
- 连续累计口径为合同分段月单价 × 数量 × 有效时长 ÷ 30 天，统计实际激活后至当前业务时间、合同截止或实际终止的交集。未激活订单、边缘 Token 业务不产生租金。
- 实时曲线显示最近 60 秒的当日累计租金。分时柱状图与周期累计曲线共享同一计量来源；未来时间留空。
- 小时趋势显示过去 48 小时的租金，布林带采用 20 个小时观测值的均值 ± 两倍总体标准差。当前未满小时以星号标注，按已发生时长累计；前 19 个观测不绘制布林带。租约不变时，完整小时收入和布林带可以保持水平。
- 产品、机房、租户贡献按所选周期汇总。合同明细支持 CSV 导出。
- 租约异常仍保留合同计费。暂停、维护、退出后业务时钟不推进，统计随之暂停。
- 原账单仍按向上取整的计费天数结算。因此连续累计租金与账单应收可能存在时间和结算进位差异；页面分别展示合同、累计、已出账应收、实收、待收。
- 年末合同累计预计只汇总现有已签合同的有效区间，不推测后续订单或续租，不计未激活订单。

这次未提供新产品报价，目录默认显示「待报价」。在管理后台进入维护后，打开「产品目录」，填写单位月价（人民币分）。未设置有效正数报价的产品无法创建租赁样例。成套编排会校验设备 GPU 型号与卡数；X1 不出现在租赁产品选项中，底层也拒绝边缘租赁。

产品目录不等同于硬件库存。此次升级保留已有硬件数量、现有历史产品、订单及账单，不自动添加 4090 或 5090 库存。可在「设备与资源」维护真实需要展示的节点。

## 模型 Token 排行

布局参考用户提供的 [模型排行榜](https://api.x-token.co/rankings)，本地展示模型用量、提供方份额及明细。支持当日与累计切换，按输入与输出 Token 之和排序，输出速率单独展示。

演示路由包含 GPT-4.1、Claude Sonnet 4、Gemini 2.5 Pro、Llama 3.3、DeepSeek V3、Qwen3、GLM-4.5、Kimi K2。路由名称与提供方在后台「Token计量」逐条编辑。展示的是本地模拟计量，未接入参考站点实时数据，亦不声称厂商是本平台客户。历史计量及新增产量均按所属路由汇总；暂停、恢复、迁移延续路由归属。

## 数据升级及验证

旧数据库首次升级前自动备份，补充产品与模型元数据，不改硬件容量和既有财务记录。旧内容包先校验原始 SHA-256，再补充元数据；管理员密码保留在本机。

- `npm test`：业务、计量、财务边界、模型合计、迁移与原有回归。
- `npm run build`：主进程与渲染端类型检查及生产构建。
- `npm run test:commerce`：独立测试数据目录中的真实 Electron 页面、后台、编排、CSV 和重启验证。
- `npm run test:ui`：原业务视图、后台编辑、导入导出及重启回归。

截图及桌面测试结果位于 `output/playwright/v2.6.1/`。产品运行仍为 Windows 本地演示模式。

# CaaS 2.6.1 全国资源预置版

2026-10-23。在 2.6.0 租赁统计和模型排行的基础上，增加全国资源样例。

- 13 处中心机房：南宁、成都、内蒙古、北京、上海、广州、武汉、西安、沈阳、哈尔滨、乌鲁木齐、兰州、拉萨。
- 31 台边缘盒子，覆盖大陆 31 个省级地区，坐标使用城市示例位置。
- 共 111 个节点、570 张 GPU；新增中心节点包含单卡 RTX 4090 和八卡 RTX 5090，可匹配已有产品。
- 初始 107 个节点在线、4 个离线，已分配 GPU 212 张；新增容量为空闲资源。现有租约和已收账款不变。
- 后台「机房地图」可修改名称和坐标；「站点与节点分组」支持新增站点；「设备与资源」可新增和编辑节点的归属、规格、状态、边缘位置。
- 全国地图标签自动避让，多机房曲线图支持滚动图例，节点数、卡数、图表与数据库联动。

先正常退出旧版，再启动本版。旧 SQLite 在追加全国样例前会自动备份；本机账号、已有节点、报价、合同和草稿均保留。追加只执行一次，后续后台修改和删除的节点不会在重启时重新生成。

交付包包含「全国预置数据.sqlite」和「CaaS-Standard.caas.json」，均不含管理员密码。日常使用直接启动应用即可自动预置；需要整体恢复时，优先在后台导入内容包。SQLite 文件为独立标准样例，不要用它覆盖含自定义业务的数据库。

预置资源与位置为本地演示数据，不代表已核实的实体机房部署。

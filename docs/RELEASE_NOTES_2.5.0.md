# CaaS 2.5.0 交付说明

发布日期：2026-10-22。Windows x64 离线桌面客户端，基于原有代码增量升级。

## 本次完成

- Token 每秒模拟产出；日累计与历史累计由相同增量驱动，精确千分位数值和紧凑值自然过渡。UTC+8 跨日、暂停、休眠及重启恢复。
- 当前生成速率、60 秒平均速率、滚动一分钟总产出、120 秒动态曲线、分钟产量。生成历史最多 3600 点，图表显示有界窗口。
- 后台增加 Token 生成设置：固定 / 自然波动、速率倍率、波动幅度。原有计量记录继续支持初始值与基础速率编辑。
- 导航栏约 300ms 平滑折叠至 68px，保留全部子菜单入口与悬停名称；状态记忆、地图及图表自适应。
- GPU 型号资源占比显示总卡数、各型号卡数及百分比；按卡数计算，统一处理百分比舍入尾差。
- 总览 12 个主要 ECharts 模块：型号占比、任务状态、Token 实时趋势、Token 分钟产量、资源利用率趋势、机房资源监控、机房 GPU 负载趋势、型号分配、GPU 时间负载矩阵、型号负载、节点 TOP8、任务提交与结束趋势。保留 3 项资源水位与迷你曲线。
- 资源波动具有共同负载节奏及节点差异；型号、容量和分配数不随动画随机变化。任务趋势使用现有任务 / 实例记录，未伪造任务完成事件。
- 地图保留既有中国 3D 轮廓与点位，增加边缘接入飞线及沿线光点，约 3 秒循环；悬停提示联动在线数量、卡数和负载。
- ECharts 实例复用、ResizeObserver 尺寸适配、离屏图表降低更新、卸载清理、减少动态效果偏好。
- 每秒更新内存与展示，约每 5 秒检查点保存，休眠和正常退出补保存。避免每秒重写基线、配置和全部日志。

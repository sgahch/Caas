# CaaS 2.6.2 删除修复版

2026-10-28，基于 2.6.1 更新。

- 修复单条删除把记录自身误判为引用，导致无关联记录也无法删除的问题。关联判断按实际字段及目标类型进行，不把名称、说明或其他类别的相同编号算作引用。
- 「设备与资源」增加「删除设备及关联」：确认前逐类列出全部受影响记录及编号，一次移除选中设备和相关订单、任务、实例、用量、计量、账单、告警及日志。
- 完整处理业务迁移后的历史关联；确认窗口说明可能涉及其他设备上的关联业务记录。其他设备、机房、共享租户及产品保留。
- 订单、任务和实例页的「移除整套」继续保留设备。清理失败时回滚草稿，避免留下部分删除的数据。

## 升级

1. 正常退出旧版，包括管理窗口。
2. 解压更新包，直接运行「CaaS-Portable-x64.exe」，或用「CaaS-Setup-x64.exe」安装更新。
3. 使用原有本机管理员账号登录。程序继续使用原数据库，不需要恢复出厂，也不需要导入标准数据。

本次升级不更改数据库结构，不自动删除数据。建议先在后台导出内容包留存。

## 删除设备

1. 打开管理后台，在「工作台与数据维护」选择「编辑数据（进入维护）」。
2. 进入「设备与资源」。无引用的设备点击「删除」；有引用的设备点击该行「删除设备及关联」。
3. 核对弹窗列出的设备及关联业务编号，点击「确认」。取消则不作修改。
4. 点击「保存并应用」使更改生效。只保存草稿不会改变展示端正式数据。

「删除设备及关联」也会移除相关业务及历史计量、账单；请按确认窗口列出的范围核对。应用前程序会自动备份，可在工作台预览并恢复。

# CaaS v2.5.3 使用说明

## 安装与启动

解压完整交付 ZIP。安装版打开 `CaaS-Setup-x64.exe`，选择安装目录，按向导完成；便携版直接打开 `CaaS-Portable-x64.exe`。两种形式选择一种即可，运行不需要 Node.js、npm、浏览器或数据库服务。便携版会解压运行文件，首次启动可能需要稍等。

目标平台为 Windows 10 22H2 / Windows 11 x64，实测范围见《实际测试记录》。程序未签名，目标电脑的系统或组织策略提示以实际环境为准，不需要关闭安全软件。

升级前在后台导出内容包作为保留副本，正常退出旧版，包括其管理窗口，再安装或打开新版。不要删除数据库；新版兼容旧库及旧内容包。旧版安装包不保证能读取新版数据。

## 数据性质与位置

本软件用于离线展示与业务流程验证。设备状态、算力、遥测、推理调用、Token、租约和账单为本地模拟；品牌和业务内容修改真实保存到本机 SQLite。真实设备代理、远程任务执行、服务端多用户和真实支付不在本版范围内。

数据目录固定为 `%APPDATA%\CaaSDesktop`，数据库为其下 `data\caas.sqlite`。安装版、便携版使用同一 Windows 用户的相同数据；修改平台名称、移动 EXE 或更换安装目录不会迁移数据。卸载默认保留数据。复制 EXE 不会带走修改过的内容，跨电脑迁移请使用内容包。

## 展示窗口

八个视图为总览、任务队列、调度策略、实例管理、资源监控、租赁订单、计量计费和告警中心。计量计费有账单与用量两个页签，合计九张主表。表格可搜索、筛选、排序、分页、查看详情及导出 CSV；CSV 导出当前筛选下的全部匹配行。

- `Ctrl+Shift+M`：打开本地管理后台。
- `Ctrl+Shift+D`：显示或收起操作面板，提供“暂停”“继续”“业务场景”等入口。
- `F11`：进入或退出全屏。

总览右上角为电脑当前北京时间，每秒更新。底部“数据时间”是持久化的业务时钟，决定遥测、Token 和合同推进；两者可以不同。暂停、维护和预览不冻结顶部真实时间。

图表每秒读取一次，表格刷新可设为 2/3/5/10/30/60 秒。若提示“数据更新已暂停”，点击“恢复更新”或操作面板“继续”；暂停状态跨重启保存。维护和预览由后台解除。关闭或休眠期间不补算 Token。

总览提供 12 个主要图表模块及资源水位。曲线默认显示最近两分钟，首次进入预填演示历史；资源主趋势可切换已有一小时样本。Token 分钟图的悬停提示标明预填历史与当前分钟样本秒数，避免将不满一分钟的柱误读为完整分钟。图例可切换趋势序列。设备容量、分配数量、合同和历史账单不会为动画随机改变。暂停任务会保留资源配额。

推荐 1920×1080 查看完整大屏；1366×768 下可向下滚动查看下部图表和表格。地图需要 WebGL，加载失败时按提示检查显卡和硬件加速。

## 地图与设备

青色标记为中心机房，紫色点为已定位的边缘盒子；离线或异常设备变暗。默认全国总览，省份下拉筛选点位；悬停或聚焦查看设备编号，点击进入详情。“查看设备”进入资源监控并带入筛选。

标准 31 台盒子的位置是示例。后台“设备与资源”可编辑省份、城市、归属租户、接入阶段和坐标；经纬度均为 0 表示待定位。待定位设备仍计入数量及列表，不生成虚构点位。真实注册及部署流程需后续设备端和服务端接入。

## 本地管理员

首次打开后台，设置 8～200 个字符的本机密码；以后使用该密码登录。没有默认密码或免认证重置入口，请自行妥善保管。关闭管理窗口或退出登录后会话失效，可在“管理员设置”修改密码。

展示面板上的租户或管理员文字是显示内容，不授予后台权限。内容包不会导出账号、密码哈希、盐或会话；目标电脑使用它自己的本地管理员。

## 草稿、预览与应用

品牌、Logo、文案、显示编号、地图名称和策略说明可在对应菜单编辑。一个可恢复草稿与正式内容分开保存：“保存草稿”落盘，“隔离预览”查看冻结副本，“保存并应用”发布并同步展示窗口。

Logo 支持 PNG/JPEG/WebP，最多 5 MiB、2048×2048。图片内容保存于配置中，原文件移动或删除后仍可使用，并随内容包迁移。

显示编号与内部 ID 分开。修改显示编号不破坏关联，同类编号不能重复。策略可编辑名称和说明，底层四个规则槽位及优先级保持固定。

## 编辑业务数据

工作台点击“编辑数据（进入维护）”，结算并暂停业务时钟，锁定展示端写入。随后可维护设备容量、租户、产品、合同、任务、实例、遥测、调用、Token、用量、账单、告警和日志。

表单提供关联下拉、时间和数字字段。金额单位为人民币分，容量为 GB。成套编排向导创建关联记录。所有可维护记录统一点击“删除”，确认窗口列出将清理的记录类别、数量和编号，不再要求先手动解除关联或另选“移除整套”。

- 删除站点：同时删除所属设备及关联业务，自动调整保留站点的地图连线和显示配置。删除边缘分组会同时清理所属边缘设备。
- 删除设备、订单、任务或实例：清理相应业务及完整历史；迁移过的业务可能涉及其他设备上的历史记录，其他设备本身保留。
- 删除租户：清理该租户的业务和历史记录，解除其边缘设备归属，保留机房、硬件、产品和其他租户。
- 删除产品：清理使用该产品的订单及关联业务，解除设备上的产品绑定，保留硬件、租户和其他产品。
- 单独删除用量、Token 计量、账单、告警或日志：清理所选记录及依赖它的记录，不反向删除所属订单、任务或实例。例如删除用量段会同步移除该段的 Token 计量。

确认后只修改草稿，点击“保存并应用”才生效，应用前自动备份。已结算账单、历史用量和累计 Token 也可能随关联记录一起删除，请核对范围。取消不修改数据，清理校验失败则回滚本次删除。至少保留一个中心机房；四个固定策略仅支持修改名称和说明。

“遥测与曲线”可按节点设置固定值或六项指标的范围和变化间隔。离线节点不自动更新；固定模式适合准备准确截图。历史曲线高级编辑按表单说明输入。

结构草稿可暂存未完成关联，正式应用前会检查容量、引用、时间、账单和 X1 禁租等规则。校验后查看影响并确认整体替换，系统先备份再原子应用；应用后保持暂停，核对完成再点“继续”。维护中退出应用，重开仍保留草稿和冻结状态。

“放弃草稿 / 退出维护”保留原正式内容，并恢复进入维护前的播放选择。

## 重置、备份与恢复

- “重置本轮”：回到当前发布基线，保留品牌与自定义场景。
- “恢复出厂内容”：先自动备份，再恢复标准内容，保留本机管理员。
- “恢复备份”：先预览，确认后备份当前内容，再整体恢复。

自动内容备份保留最近三次。数据库结构升级的内部一致性备份位于 `internal-db-backups`，可能包含认证信息，仅用于同机技术回退，不作为客户迁移包。

## 导出与跨电脑迁移

工作台选择“导出内容包”，保存 `.caas.json`。包中包含发布配置、基线、运行状态、已保存草稿与 Logo。另一台电脑打开后台并使用其本地密码，选择“导入内容包（先预览）”，核对后确认。

2.4.3 会先验证原包 SHA-256，再转换旧版策略和遥测等兼容值；旧包、旧备份的运行数据、基线、草稿都受支持。损坏摘要和无效业务关联不会绕过校验。导入上限 50 MiB，导入后生成新的运行 ID，默认暂停；有结构草稿时进入维护。

两台电脑后续独立变化，不自动同步。未发布的草稿不会被当作已发布内容，导入也不替换目标机密码。

## 故障处理

保存失败会显示错误，原有效数据库保留。先检查磁盘空间及数据目录写权限，保留错误截图和数据；不要把删除数据库作为常规排错方式。遇到更高数据库格式会停止写入，使用对应新版程序处理。

遇到画面不更新，先区分普通暂停、维护和隔离预览。顶部真实时间正常而业务时间暂停属于正常状态。若多个版本同时打开，只会聚焦当前已有客户端；请先退出旧版再打开新版。

## 2.5 实时 Token 与导航

顶部“≡”按钮以约 300ms 过渡折叠导航，收起后保留全部菜单及子菜单图标，悬停显示名称；状态随本地客户端保留。右侧地图及图表随容器适配。

顶部 Token 卡同时显示精确整数与紧凑单位，每秒自然过渡。下方生产面板显示当前 Tokens/s、最近 60 秒平均速率、滚动一分钟总产出、120 秒速率曲线及分钟产量。运行实例的增量同时计入日累计和历史累计；每日 UTC+8 00:00 切换日统计，累计不清零。统计日期以底部业务时钟为准。

管理后台“Token 生成设置”控制固定 / 自然波动、速率倍率（0～100）和波动幅度（0～80%）。修改后“保存并应用”；倍率 0 停止产出。基础速率和初始累计可在维护模式下通过“Token计量”逐实例修改。运行 / 暂停在工作台中控制。资源型号和卡数继续由设备记录计算，容量编辑要满足原有配额与关联规则。

累计与速率历史在主进程统一生成；正常退出和进入休眠保存最新进度，运行中约每 5 秒检查点保存。意外断电或强制结束最多损失约 5 秒的未保存增量。关机、关闭和系统休眠期间暂停，恢复时不补算离线时间。页面切换不影响产出。

预填历史为演示曲线并明确标记；后续实际生成的每秒模拟增量与累计精确一致。本软件没有新增真实设备接入模式。

## 2.5.1 资源监控更新

资源监控页可滚动查看 12 张图，含型号占比、机房曲线、资源雷达、两种热力矩阵及温度负载散点。图表使用统一资源数据；点击型号可筛选列表，点击设备矩阵、散点或节点排行可查看设备详情。标准场景含 8 种 GPU 型号，总卡数仍为 320。曲线使用不规则的可复现模拟波动；固定遥测模式及后台上下限仍生效。

## 自定义客户地区

按 Ctrl+Shift+M 打开后台，在“工作台与数据维护”进入“编辑数据”，切换“租户”，编辑目标租户的“客户地区”。可以自由填写美国、日本、新加坡或其他中英文国家 / 地区名称（1～100 字），确认后点击“保存并应用”。相关任务、实例、订单、账单、用量、筛选和 CSV 自动同步；内容包及重启会保留修改。

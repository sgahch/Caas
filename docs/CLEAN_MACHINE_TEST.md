# 干净机补充验收

以下项目均待在目标环境实际执行后填写。记录exe的SHA-256、Windows版本、CPU/GPU、用户、分辨率、系统缩放与每项截图。

1. 在没有Node.js、Python、开发工具或数据库服务的Windows10/11 x64机器，新建测试用户；复制两种完整exe及标准内容包，断开网络后才开始安装。
2. 运行安装版并首次启动；确认无运行时下载、外部浏览器、终端或手工后端。验证七张指标卡、12 个主要图表、3D 地图及八视图，保留首次启动录像或截图。
3. 首次设置本地密码；改品牌、Logo、地图名和编号并应用；退出应用、重启Windows，核对全部保留。
4. 进入维护，改空闲设备容量，核对GPU/CPU等来源合计；应用后应暂停。测试放弃草稿与重启维护恢复。
5. 单独运行portable，再与已安装客户端交叉启动；应共用当前用户的数据，且只有一份展示/管理窗口，不重复计量。
6. 恢复出厂后暂停时钟，逐条执行三条主场景，核对DEMO_GUIDE数值及CSV全部分页行数。
7. 从电脑A导出内容包，电脑B用自己的本地密码导入，核对图片、场景和草稿。A再改内容，B不应自动变化。
8. 在1366×768、1440×900、1920×1080及Windows125%/150%缩放，检查标签对齐、表格滚动、窗口最小化/最大化/拖动、F11进入退出。
9. 覆盖安装后确认内容保留；卸载后确认按说明保留数据。遇到错误保留日志和数据库，不将删除数据库当作通过手段。

结果表建议列：项目、环境、操作、预期、实际、通过/失败/待验证、证据位置。没有运行过的项目继续保留“待验证”。

10. 连续观察至少 30 秒的 Token 精确数字、速率和曲线；测试暂停、休眠、重启、UTC+8 跨日、后台速率与 GPU 型号数量修改，核对累计与分布。

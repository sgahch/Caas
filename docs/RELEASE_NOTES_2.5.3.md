# CaaS 2.5.3 交付说明

发布日期：2026-10-22。Windows x64 桌面客户端。

## 客户地区自由编辑

管理后台 → 工作台与数据维护 → 进入编辑数据 → 租户 → 编辑目标租户 → 客户地区。

客户地区改为自由文本，支持美国、日本、新加坡及任意中英文国家、地区或自定义名称，1～100 字。编辑后确认，再点击“保存并应用”。租户管理列表增加客户地区列，便于直接查看。

同一租户的任务、实例、租赁订单、账单、用量统计、详情、地区筛选及 CSV 自动读取该值。导出 / 导入内容包和重启后保留修改。旧有“海外客户 / 国内客户”仍可使用，不自动更改任何租户的原地区。

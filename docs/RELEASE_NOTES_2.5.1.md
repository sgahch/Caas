# CaaS 2.5.1 交付说明

发布日期：2026-10-22。Windows x64 离线桌面客户端，在 2.5.0 基础上增量升级。

## 本次更新

- GPU 型号由 3 种扩展为 8 种：H100、H200、H800、A100、A800、B300、RTX 5090、L40S。标准场景仍为 320 张 GPU 卡，已分配 212 张；卡数、占比、分配图及后台筛选统一联动。
- 扩展型号分配给标准场景中没有业务引用的空闲节点。旧库首次升级前自动备份，保留用户自定义型号、容量、业务引用及主要演示场景；升级记录持久化，重复启动不会再次改写。
- GPU、CPU、内存、存储、温度及 Token 曲线改为多尺度不规则变化，加入短时抖动及偶发峰谷，降低线条平滑度。相同时刻数据可复现，刷新不重绘随机历史，Token 的秒级产量与累计仍精确一致。
- 资源监控页由 2 图扩展为 12 图：资源实时脉动、机房负载轨迹、型号占比、资源多维雷达、型号分配、型号负载、GPU 时序热力、全量设备矩阵、温度与负载散点、节点 TOP8、机房水位、边缘地域分布。
- 雷达图按在线设备容量加权，散点每点对应一台在线设备，可点击查看详情。三列 / 两列自适应布局，增加层次渐变、冷色光晕和仪表编号；保留设备列表及原有操作。
- 总览保留 12 个 ECharts 图表和 3 项资源水位。8 型号图例适配小窗口和折叠导航；本地打包，无运行时联网依赖。

## 验证和交付

- 44 项领域、服务、数据及地图自动化测试通过；生产构建及主进程 / 渲染端类型检查通过。
- 真实 Electron 界面验收通过：总览 12 图、资源监控 12 图、8 型号、1920 / 1366 布局、导航折叠及图表尺寸适配、30 秒 Token 增量一致、后台调速、资源修改、暂停 / 休眠 / 重启恢复。页面脚本错误、ECharts 警告和 HTTP(S) 请求均为 0。
- 原有完整界面回归及 10 个历史内容包兼容检查通过。最终 EXE、旧 SQLite 与交叉单实例验证记录随交付包提供。
- 包含安装版、免安装版、标准内容包、源码 ZIP、界面截图、说明和 SHA-256 清单；最终二进制内嵌代码与本次构建核对。

## 数据和环境范围

设备、遥测、Token、任务与计费为明确标识的本地模拟数据。历史曲线首先预填演示样本，之后由本地时钟驱动；休眠和关闭期间暂停，不补算离线产出。后台配置为固定值的设备仍保持固定值。

本次在开发机进行桌面自动化与模拟离线 / DNS 阻断验证；安装器内容解包后实际运行。未重新操作安装向导，未在另一台干净机物理断网、Windows 10、真实 125% / 150% DPI 下执行验收，未执行数小时压力测试。

# CaaS 2.5.2 交付说明

发布日期：2026-10-22。Windows x64 桌面客户端，基于 2.5.1 增量更新。

## 本次调整

- 删除总览右上角的“模拟数据”角标及 Token 区域“演示数据”角标。
- 清理图表副标题、切换选项、热力图与分钟图悬浮提示中的“演示历史”“演示负载”等字样，统一使用历史样本及资源描述。
- 后台 Token 设置标题与说明同步清理，参数错误信息使用中性名称。
- 删除角标对应样式。运行状态、时钟、8 种 GPU 型号、12 张资源监控图及动态曲线继续保留。

## 验证与交付

本版执行渲染端与主进程类型检查、生产构建、真实 Electron 各页面及后台文案检查、1920 / 1366 窗口截图、完整界面回归、历史内容包兼容检查及最终 EXE 回归。详细结果随 evidence 交付；安装版、免安装版、源码与标准内容包均更新至 2.5.2。

本次仅调整界面文字和显示元素，数据来源和引擎保持原有本地模拟方式。目标电脑、物理断网、Windows 10 及真实系统 DPI 的验收范围沿用前版说明；安装包内容经解包实际运行，未重新操作安装向导。

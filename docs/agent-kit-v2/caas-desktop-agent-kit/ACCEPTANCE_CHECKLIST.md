## A Windows 与离线运行

- [ ] A01 记录 Windows 版本、架构、CPU/GPU、缩放、用户类型和磁盘路径。
- [ ] A02 在新用户或干净测试系统，先断网，再安装和首次启动；不预热在线缓存。
- [ ] A03 无需 Node.js、npm、Python、数据库服务或开发工具；启动不下载运行时、字体、地图、驱动和在线授权。
- [ ] A04 安装版和便携版分别通过；没有外部浏览器窗口、终端或手动后端启动步骤。
- [ ] A05 独立窗口最小化、最大化、拖动、关闭、全屏进入退出有效；标题栏点击区域正确。
- [ ] A06 同一用户重复启动及 installer/portable 交叉启动只激活一份应用，不重复写入或计量。
- [ ] A07 中文用户名、带空格路径及可写用户目录可用，数据不写安装目录或临时解压目录。
- [ ] A08 记录实际包体、冷启动表现、签名状态和系统提示；未测架构没有标为支持。

## B 已确认 UI 与页面

- [ ] B01 真实 3D 挤出地图、七卡、右侧三环、底部表符合已批准参考图。
- [ ] B02 地图点位、省界、边缘类型、弧线、标签和机房筛选联动正常；不是效果图贴图。
- [ ] B03 八业务视图、九主表、字段、筛选、排序、搜索、分页和详情均按 PAGES 覆盖。
- [ ] B04 三个窗口尺寸、100%/125%/150% 系统缩放无明显裁切、重叠和标签漂移。
- [ ] B05 调整窗口、切页、打开关闭管理预览后没有残留动画循环；低动效仍保留真正 3D。
- [ ] B06 状态颜色、客户地区、金额及用量单位一致，X1 GPU 不适用字段正确。

## C 后台编辑与发布

- [ ] C01 管理员首次创建、登录、登出有效，显示身份与本地账号分开。
- [ ] C02 前端全部文案、表格与详情字段有编辑入口或计算来源映射；包级元数据和规则事实明确受约束。
- [ ] C03 平台名、Logo、导航/表头等文案、节点显示编号和机房标签可改且全页同步。
- [ ] C04 在维护模式改设备容量及相关分配，首页总量、分配、空闲、监控和详情可复算。
- [ ] C05 租户、产品、订单、任务、实例、用量、账单、告警、日志和调用样例可合法新增编辑删除。
- [ ] C06 遥测当前值与曲线终点一致，固定值/采样/波动参数可用；Token 当日和累计口径一致。
- [ ] C07 四策略说明可编辑，未实现的算法状态不会仅改变展示文字而伪造生效。
- [ ] C08 草稿保存后重开可恢复；草稿预览不推进正式 Token、不执行正式订单动作。
- [ ] C09 纯文案应用保留编辑期间发生的订单终止等运行变化，避免旧快照覆盖。
- [ ] C10 场景编辑显式暂停；运行命令被拒绝；整体应用先备份确认且单事务，新 runId 使旧回调失效。
- [ ] C11 应用后展示自动更新，关闭软件重开仍保存；数据库失败没有成功提示或半更新。
- [ ] C12 重置本轮保留 CMS；恢复出厂明确影响、可回退并保留本地账号。

## D 原演示规则

- [ ] D01 恢复标准种子后 GPU 320/212/108、节点 44/48、CPU 8192/5120/3072、月租 286400 可复算。
- [ ] D02 租赁优先场景：目标 Token 让出资源，无关任务保留，精确结果按 DATA_RULES。
- [ ] D03 边缘不足的新任务回落中心，原边缘实例继续，X1 不产生租赁或租金。
- [ ] D04 终止租约统一结束关联任务/实例并释放资源；旧已付账单保持，未出账结算按规定取整。
- [ ] D05 空闲填充一次执行，重复、重启和再次终止不复活同一个填充事件。
- [ ] D06 暂停保留资源和停止新增产出，恢复不重复分配；失败重试原因可查。
- [ ] D07 迁移原子保留实例 ID，用量按节点分段，失败不释放原资源。
- [ ] D08 续租不重复计当前月租，不改历史已出账单；确认/忽略告警不自动恢复设备。
- [ ] D09 10/30/60s 与手动刷新、双窗口查询不重复 Token，关闭期间不补算。
- [ ] D10 用量和账单 CSV 包括当前筛选全部行，中文、金额、转义和合计一致。

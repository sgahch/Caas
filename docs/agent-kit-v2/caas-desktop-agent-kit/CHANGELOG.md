# CaaS v2 桌面版变更与迁移说明

2026-10-19。用户新增：可下载 exe、独立应用窗口、无需联网、可编辑前端全部信息的本地管理后台。

## v1 到 v2

| 事项 | v1 | v2 |
|---|---|---|
| 运行入口 | 本地 HTTP 启动静态页面 | 双击 Windows 安装版或免安装 exe |
| 窗口 | 外部浏览器 | Electron 展示窗口与最多一个管理窗口 |
| 持久化 | 演示仓库与 localStorage | 主进程 SQLite、事务与数据库迁移 |
| 后台 | P1 可选 HTTP 与 SQLite | 首版必须交付本地真实 CMS；不要求 HTTP 服务 |
| 可编辑范围 | 预置演示数据和运行按钮 | 文案、实体、遥测、历史样例、点位、草稿预览、发布 |
| 数据回退 | 恢复固定初始种子 | 重置当前运行、恢复出厂、备份恢复分开 |
| 多窗口同步 | 单浏览器标签验收 | 两窗口共享服务与主时钟，应用后通知 |
| 离线验证 | 已构建包从 localhost 打开 | 干净 Windows 用户先断网，再首次安装与启动 |
| 对外交付 | 静态产物和启动脚本 | installer 与 portable exe、源码、数据包和说明 |
| 已批准 UI | 3D 中国地图、六导航八视图 | 沿用并增加窗口、全屏和 DPI 适配 |
| 真实算力能力 | 模拟 | 继续模拟，本地保存为真实功能 |

## 已有工程如何迁移

1. 保留视图、组件、主题、地图与领域纯函数；先梳理真实代码，不重建一套相同 UI。
2. 将正式业务状态与模拟时钟移入主进程。renderer 的 DesktopRepository 仅封装 preload，不能一边写 localStorage、一边写 SQLite。
3. 将 v1 revision 拆分为业务 CAS 的 businessRevision 和快照序号 runtimeRevision，新增 configRevision、runId、publishedBaseline 和唯一草稿。更新类型与错误码后再并行修改页面。
4. 清理“浏览器启动”交付说明和可选后端判断，改为正式包本地资源协议；开发用热更新地址只在开发模式启用。
5. 将页面散落文案收敛到 UiCopy 注册表，将显示编号与内部 id 分开，加入编辑入口映射。
6. 新增维护模式与整组校验，避免容量、状态和历史信息直接覆写运行态；基础资源 CRUD 不能破坏正在演示的订单。
7. 开发时已经录入的真实用户内容先保留与备份。如需迁移 v1 浏览器数据，提供显式导出并由 v2 导入兼容入口，不扫描或读取其他浏览器个人数据，也不无提示替换当前数据库。
8. 先测试最小 Windows exe，再补完管理表单和全功能。生产包可以离线运行，不代表未准备依赖的开发环境能够离线重新编译。

## 本版文档的关系

旧 P1_BACKEND.md 不再随新版执行包提供。正式实现以本版 PROJECT_PLAN、ARCHITECTURE、LOCAL_DATA 和 ADMIN 为准，PAGES 与 DATA_RULES 已迁移到桌面语境。MAP_3D 保留原地理资产和批准视觉。标准场景数值仅针对未修改的标准种子，不要求用户新编辑的场景保留原总数。

# CaaS v2 开发任务清单

按依赖推进，完成一项即继续。阶段验收用于发现错误和留存证据，不要求每一步等待用户确认。预计工时由实施 Agent 查看实际工程后估算，本表不预设未经确认的交期。

## D0 桌面最小闭环

- [ ] D01 检查现有仓库、用户修改、开发环境和 Windows 构建环境；记录继承代码与迁移范围。
- [ ] D02 锁定共享类型、UiCopy 键、稳定 id 与 displayCode、configRevision、businessRevision、runtimeRevision 与 runId、主时钟与管理草稿协议。
- [ ] D03 建立 Electron main/preload/renderer 构建，明确生产入口和本地协议；配置展示窗口、单管理窗口和应用退出。
- [ ] D04 建立 SQLite 元信息、领域数据、配置、基线、草稿、账号、事件和命令去重存储，确认只有主进程写入。
- [ ] D05 实现本地管理员初始化与登录、受限 bridge、请求来源检查和参数验证；非法管理请求被拒绝。
- [ ] D06 实现一条后台编辑、事务保存、展示通知和关闭重开链路，验证磁盘失败不会返回成功。
- [ ] D07 最小包内包含本地地图和原生数据库文件，构建 NSIS 与 portable；在 Windows 断网首次运行，检查运行时无需下载。

D07 未通过前可以继续完成不依赖它的页面工作，但不能把桌面运行风险留到最终交付才第一次检查。版本与命令记录在 docs/dependencies.md、docs/VERIFICATION.md。

## D1 设计还原与统一数据

- [ ] D11 落地批准 UI 的主题、窗口标题栏、六菜单、顶栏、七卡、地图、三环和节点表。
- [ ] D12 从本地 GeoJSON 生成带洞和 MultiPolygon 均正确的地图；共用投影，标签与点位同步，点击机房筛选表格。
- [ ] D13 建立 DATA_RULES 的标准种子、实体关联、计量基线与可复算指标，冻结标准验收时钟。
- [ ] D14 所有业务组件读取同一发布配置与运行快照，禁止各页面自己随机造数据或写 KPI 常量。
- [ ] D15 检查窗口缩放、最大化、全屏、DPI、地图生命周期和低动效模式，保存真实客户端截图。

D11 与 D13 可在 D02 后并行；D12 的资源路径需继承 D03/D07 已验证方案。

## D2 完整展示业务

- [ ] D21 完成 PAGES 的八视图九主表、全部字段、筛选、排序、搜索和分页。
- [ ] D22 完成节点、实例、订单、用量、日志详情，按稳定 id 跳转，不复制过时实体。
- [ ] D23 实现主进程统一命令：调度、暂停恢复、终止、重试、迁移、续租、告警确认忽略。
- [ ] D24 完成资源守恒、X1 禁租、历史分段、整数金额、账单保护、Token 去重与命令幂等。
- [ ] D25 完成主时钟与显示刷新分离，10/30/60s 不重复计量，窗口重开及旧响应不回滚。
- [ ] D26 完成标准三条业务主线、空闲填充、失败重试、续租、迁移和全筛选 CSV。

## D3 本地管理后台

- [ ] D31 建立独立管理布局与菜单、字段搜索和每个前端字段的编辑来源映射。
- [ ] D32 完成平台名、Logo、UiCopy、显示编号和受控主题配置；导入素材复制到本地内容库，不能引用源电脑绝对路径。
- [ ] D33 完成机房地图点位、节点资源、租户产品、订单任务实例等关联表单；新增、修改和删除显示影响。
- [ ] D34 完成遥测当前值、近一小时采样/参数、Token 基线与速率、日志和调用记录样例编辑。
- [ ] D35 完成用量与账单样例、告警及四策略说明编辑；约束状态、金额、引用与不可伪造的生效事实。
- [ ] D36 实现单草稿、恢复草稿、隔离预览、纯配置 patch 应用；配置更新保留当前运行进度。
- [ ] D37 实现场景维护模式、暂停、备份、影响摘要、完整校验、原子应用、放弃恢复和新 runId。
- [ ] D38 实现重置本轮与恢复出厂的不同语义，并进行一次“全栏目后台改动 → 展示 → 重启”检查。

D32 可与 D21 并行；D33/D35 依赖领域约束。管理功能不能绕过 D24 自己写另一套账单或资源规则。

## D4 数据与恢复

- [ ] D41 定义版本化 .caas.json 演示内容包，包含配置、基线、当前运行态和本地素材，明确导出体积限制。
- [ ] D42 导出一致快照与 SHA-256 校验；排除密码、会话、绝对路径和开发密钥。
- [ ] D43 导入先校验并预览内容，再备份和确认整体应用；损坏包、未知版本或违规关联不污染当前数据。
- [ ] D44 实现本机自动备份、列表和恢复；原始数据库恢复与跨机器内容导入分开，不互相覆盖账号。
- [ ] D45 实现 schema 迁移、更新失败回退、更高版本拒绝写入和管理员明确的数据清除入口。
- [ ] D46 在两个独立 Windows 用户环境或两台电脑验证内容迁移，复制 exe 不携带已编辑内容的行为写入说明。

## D5 最终交付

- [ ] D51 运行类型检查、领域与持久化的必要测试、生产构建和两种 Windows 打包；整理准确命令与版本。
- [ ] D52 在支持的 Windows 10/11 x64 环境先断网后安装与首次启动，确认无开发工具、无在线运行时下载。
- [ ] D53 验证双窗口同步、安装版与 portable 交叉启动、中文用户目录、带空格路径、重启与升级保留。
- [ ] D54 最终包复验业务三主线和管理链路，检查 1920×1080、1440×900、1366×768 与 DPI，完成截图。
- [ ] D55 写用户手册、演示流程、数据位置/迁移/恢复说明、构建文档、素材来源与已知限制，记录签名状态和文件哈希。
- [ ] D56 交付安装版、免安装版、源码、锁文件、标准数据包与真实验收记录；未运行项如实标明。

## 并行分工

主 Agent 管理工程、类型、路由和集成；子任务可分为桌面与数据、展示与 3D、管理与业务表单。先约定接口与文件归属，避免同时改同一份模型、全局 CSS 或锁文件。根据现有工程复用情况安排，不为并行本身拆分成多个独立产品。

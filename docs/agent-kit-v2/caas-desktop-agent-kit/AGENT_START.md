# CaaS 离线桌面版开发 Agent 启动指令

请直接实施本执行包定义的 CaaS v2 Windows 离线桌面演示平台，持续完成代码、界面、数据库、本地管理后台、打包与验收。先读取 README.md、PROJECT_PLAN.md、CHANGELOG.md、specs/ARCHITECTURE.md、specs/LOCAL_DATA.md、specs/ADMIN.md、specs/PAGES.md、specs/DATA_RULES.md、specs/MAP_3D.md、TASKS.md 和 ACCEPTANCE_CHECKLIST.md，并实际查看 reference/ui-approved.png。

先检查当前仓库和已有用户修改；有代码则增量迁移，没有代码则新建工程。默认技术为 Electron、Vue 3、TypeScript、Vite、Element Plus、Pinia、Vue Router、ECharts、Three.js、d3-geo 和 SQLite。稳定的既有前端代码可复用。按实际版本核对兼容性、原生 SQLite 二进制和打包方式，做最小联合运行验证后锁定精确依赖，提交锁文件，不用强制安装掩盖依赖冲突。

本轮已授权并必须包含独立 Windows 客户端、本地数据库、展示前端和可编辑本地后台。不要沿用 v1 的“先只做静态前端”“P1 再加后端”“客户用浏览器打开”“localStorage 保存正式业务数据”的旧决定。实际算力、硬件遥测、支付、线上实名注册和外部租赁 API 不接入，业务仍为可复算的演示模拟。

第一步完成最小桌面链路：展示窗口、单个管理窗口、受限 preload IPC、SQLite 写入、关窗重启恢复、读取本地 GeoJSON、打出最小 installer/portable，并在 Windows 断网首次运行。正式包不启动 Vite、不要求客户开终端、装 Node.js 或安装数据库、不依赖 localhost 服务和外部浏览器。不要把开发预览成功当成 Windows 包已验证。

保留已批准的深蓝 3D 中国地图 UI。必须真实生成 Three.js 挤出地形、省界、点位、光圈、少量弧线和 HTML 标签，使用随包地图资产。首页七卡、地图、右侧三环、底部节点表和六导航继续完整。不能用整张效果图或二维地图顶替 3D。随后完成原八视图、九主表、筛选分页排序搜索、详情和全部业务动作。

主进程是数据与时间权威：统一领域命令、SQLite 事务、lastMeteredAt、runId 和版本。渲染端只持快照与 UI 状态。预览不能计量，两个窗口不能重复推进 Token。X1 无租赁无租金、资源不超分、暂停保留资源、迁移 ID 稳定、终止幂等、历史账单保护等规则按 DATA_RULES 执行。

新增本地管理端，覆盖平台文案与 Logo、机房点位、设备、租户产品、订单任务实例、监控和曲线、Token 样例、用量账单、告警策略说明及数据维护。所有可见字段应有编辑入口或计算来源映射；显示编号通过 displayCode 修改，内部 id 保持稳定。派生数字由数据联动更新，不保留每个页面独立硬编码的假数据。不做自由拖拽页面生成器或可执行脚本规则编辑器。

管理流程保持轻量：一个可恢复草稿、隔离预览、保存并应用。纯展示配置合并到当前状态，不回滚演示进度；容量、关联和历史等场景结构修改进入维护模式，暂停模拟和冲突命令，自动备份、校验、显示影响后整体应用新场景。重置本轮从当前发布基线复位并保留 CMS；恢复出厂内容另行确认并保留管理员账号。

登录由本地主进程校验，密码带盐哈希，管理 IPC 必须核验会话和窗口来源。开启 contextIsolation 与 sandbox，关闭 renderer Node 集成；不暴露任意通道、路径读写、SQL 或 shell。导入导出使用文件选择框和版本化数据包，排除密码和会话；恢复、升级和失败处理不能静默删库。

最终交付 CaaS-Setup-x64.exe 和 CaaS-Portable-x64.exe、完整源码、锁文件、迁移和打包配置、标准数据包、使用说明、演示说明及验证证据。安装版和免安装版在同一 Windows 用户下使用同一稳定数据目录并防重复运行；另一台电脑用导出导入带走改过的内容。用户改平台名不能改变数据目录或破坏升级。

验证必须覆盖 Windows 10/11 x64 支持范围、断网首次安装和首次启动、无开发环境、保存重开、两窗口同步、导入恢复、升级保留、原三条主场景和后台编辑链路。检查 1920×1080、1440×900、1366×768 以及 Windows 125%/150% 缩放。保留真实运行记录和截图，尚未运行的检查写“待验证”，不预填“通过”。

常规实现选择、bug 修复和集成自主推进，阶段截图只作验证，不作为默认等待确认的关卡。必要 Windows 环境不可用时先完成其余已授权工作，明确尚缺的构建或运行证据和具体解决方式，不将未验证代码宣传成已完成客户端。必需范围与关键验证完成后交付，不继续添加未请求的系统。

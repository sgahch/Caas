# CaaS 离线桌面版 Agent 执行包

版本 v2.0，2026-10-19。按用户新要求升级为 Windows exe、独立窗口、完整演示前端、本地管理后台和 SQLite 保存。本包是可直接交给开发 Agent 的规划与素材，尚未包含应用源码或已构建 exe。

## 直接开始

将本文件夹放入开发工作区，把 AGENT_START.md 的全文交给 Agent。已有代码时增量修改；空工作区直接按默认方案开工。保留 reference/ui-approved.png 中已经确认的 3D 地图设计。

先完成 Electron 窗口、数据库写入、关闭重开和最小 Windows 打包闭环，再开发完整页面。最终交付完整安装版与免安装版，必须在断网 Windows 环境首次启动通过。

## 固定决定

后台保存和数据落盘是本次必须开发的功能。云端服务、真实算力接口、真实推理、线上注册实名认证和支付均不依赖也不自动接入。展示端保留原有模拟操作，后台编辑不能破坏 X1 无租赁无租金、资源守恒和历史账单规则。

不同电脑独立保存内容。导出和导入是跨电脑传递数据的方式；免安装程序也会使用本机稳定数据目录。平台显示名称可编辑，应用身份与数据目录名不因此改变。

## 随包素材

reference/ui-approved.png 为已认可视觉基准，不允许当整页背景代替真实控件。assets/maps 包含已下载的 GeoJSON、来源元数据、SHA-256 和署名说明。应用运行时直接读取本地副本，不从网络拉取底图、字体或图标。

## 完成定义

完成独立客户端、八视图九主表、可编辑本地后台、关闭重开保存、数据备份迁移、业务演示联动及两种 Windows exe。交付真实构建产物、源码、锁文件、操作说明和实际验证证据，不能只交网页预览或打包命令。

本版替代 v1 的静态网页运行、localStorage 业务保存和可选 P1 后端决定。细节冲突以本版 PROJECT_PLAN 和 LOCAL_DATA 为准；业务公式与标准种子仍按本版 DATA_RULES 执行。用户之后的明确要求优先于本包。

# CaaS 2.6.3 三中心与直接删除版

2026-11-04，基于 2.6.2 更新。

- 中心机房仅保留南宁、成都、内蒙古。默认共 71 个节点、320 张 GPU，31 台边缘盒子及其省份覆盖保留。
- 升级旧版时，先自动备份，再同步清理其他中心、所属设备、关联业务和历史记录，以及地图显示配置；同时处理正式数据、重置基线及已保存草稿。本机管理员账号和保留对象的自定义名称、配置保留。
- 后台「站点与节点分组」直接点击「删除」，确认一次即从草稿清理该站点及关联数据，不再提示「存在关联」而阻止删除。
- 后台「设备与资源」的「删除」同样直接清理设备及关联数据。站点删除会自动修正保留站点指向已删站点的地图连线。
- 删除边缘接入分组时会同时删除所属边缘设备及相关业务。至少保留一个中心机房。
- 应用更改后重启不会恢复已删站点。升级清理仅执行一次，此后管理员新增站点会正常保留。

## 升级

正常退出旧版的展示及管理窗口，再运行本包中的免安装 EXE，或使用安装版更新。继续使用原账号和数据库，无需恢复出厂或导入标准数据。

升级会自动清理南宁、成都、内蒙古以外的中心，包括其业务及历史数据；程序会先保存完整旧内容备份。边缘接入分组默认保留。

## 后台删除

1. 进入管理后台，在「工作台与数据维护」点击「编辑数据（进入维护）」。
2. 在「站点与节点分组」或「设备与资源」点击该行「删除」。
3. 确认窗口会显示将一并清理的记录类别和数量。点击确认后清理草稿，点击取消则保留。
4. 点击「保存并应用」发布更改，程序在应用前自动备份。

站点关联的订单、任务、实例、用量、Token 计量、账单、告警和日志会一起清理；共享租户和产品不删除。如果业务迁移到其他设备，其相关业务和历史记录也可能纳入本次清理。

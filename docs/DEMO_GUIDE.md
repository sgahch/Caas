# 2.6.1 租赁与模型用量演示

1. 在运行状态打开「算力租赁数据」，观察当日累计数字和实时曲线持续增长；切换日、周、月、年，查看柱状与累计走势。
2. 查看小时租金布林带、产品/机房/租户贡献及收款分布。租约稳定时完整小时租金不随机波动；当前未满小时按已发生时长显示。
3. 点击「导出 CSV」导出合同租金明细。对照合同与收款分组，确认累计收入、月租与实际收款分别展示。
4. 总览查看租金四项卡片，向下找到模型 Token 用量排行，切换当日与累计，查看输入、输出与提供方份额。
5. 后台进入维护，在「产品目录」给 TITANPOWER-X8 填写实际月价；在「设备与资源」成套编排中选择该产品，系统仅提供八张 RTX 5090 的可用设备。X1 不提供租赁选项。
6. 保存并应用后恢复更新，新租约产生增量租金；终止后停止新增，保留已累计与历史账单。硬件总数不随收入动画变化。
7. 在后台「Token计量」修改模型名称与提供方，应用后确认排行按新归属汇总；退出重开确认报价和归属保留。

# 2.5.0 动态总览演示

1. 打开客户端，确认总览标明模拟数据。若暂停，点击“恢复更新”。
2. 观察顶部当日 / 累计 Token 下方精确数字，连续 5～10 秒可见每秒增长。
3. 点击顶部“≡”折叠、展开导航；收起后直接点击子菜单图标，悬停可查看名称。
4. 向下滚动至 Token 实时生产面板，查看当前速率、60 秒平均、滚动一分钟产量、动态曲线和分钟柱图。
5. 查看资源趋势、机房多曲线、GPU 时间热力矩阵与排行榜；图例可切换系列。

7. 正常退出后再次打开，确认累计和配置保留。关闭、休眠期间不补算。

# CaaS v2.4.3 演示步骤与培训讲解

## 2.4 地图讲解补充

“紫色圆点代表分布在客户所在地的算力盒子，青色标记代表中心机房。现在是全国总览，我们选广东，只看该省的盒子。悬停查看城市和编号，点击看设备详情，再点查看设备进入对应列表。离线盒子点位会变暗。这里使用的是示例位置数据，实际部署后需要设备代理和服务端接入。”选择全国总览后继续其他讲解，不需要轮播。


总览右上角是当前北京时间，每秒更新；开始前先看底部“数据时间”是否推进。若页面提示“数据更新已暂停”，点击“恢复更新”；2.3旧版按Ctrl+Shift+D后点击“继续”。暂停会跨重启保留，重新安装并不会自动恢复。曲线首点等待约2秒后继续增加，维护/预览冻结则按后台流程解除。

展示窗口默认收起右上角操作按钮。当前数据为本地模拟，讲解时按本稿说明功能范围。`Ctrl+Shift+D` 打开内部操作面板，可暂停、继续或选择场景；`Ctrl+Shift+M` 打开需密码的管理后台。结束准备后再次按 `Ctrl+Shift+D` 收起面板。默认在线节点的遥测独立平滑变化，设备容量和已分配资源遵循业务记录。

## 五分钟培训讲解稿

讲解目标是让同事理解页面和操作闭环。开始前用标准场景、保持时钟运行，按F11全屏；实时曲线刚打开时只有当前观测点，等待十几秒即可形成短线。图表里的利用率会变化，资源分配与金额只随业务动作变化。

**开场，约30秒：**“这次展示的是算力调度平台的交互原型，当前使用模拟数据。我们按‘资源在哪里、任务怎么分配、运行怎么观察、费用怎么追溯’四步来看。”

**总览，约60秒：**“地图上青色标记是中心机房，紫色标记是客户部署在不同城市的边缘设备。下方曲线展示当前窗口采集的最近两分钟资源变化，可以切换到一小时历史。右边柱图比较各中心机房的GPU和CPU负载，也能切换成已分配与空闲卡数。利用率和已分配卡数含义不同：卡已经分配，不代表每一秒都满负载。”停留观察几次更新，切换两个下拉选项后切回实时模式。

**任务调度，约90秒：**“现在看一个标准租赁任务。如果没有足够的空闲资源，本地规则会尝试让目标节点上的系统Token任务让出资源，客户租赁任务获得节点，被让出的任务重新进入待调度，历史用量保留。”进入任务队列，搜索TASK-DEMO-LEASE，打开详情再点击调度，查看新状态和事件日志。“这里演示的是本地状态和资源分配闭环，执行环境及真实任务进程需要后续对接。”不要把重新入队描述成已自动重试成功。

**边缘设备，约45秒：**“边缘设备按客户实际部署城市管理，后台可维护归属和位置。标准场景可以演示本地容量不足后尝试中心节点承接。通电联网、设备注册、策略部署是产品接入流程示意，当前版本尚未连接真实设备代理。”只在标准边缘场景展示回落，不把实例详情里的同类型迁移描述为边缘到中心的无损热迁移。

**计量与追溯，约45秒：**“最后看用量和账单。当前Token按运行实例的模拟速率累积，暂停或离线停止新增；实例迁移时保留旧节点的历史记录，新用量记入目标节点。图表可以按租户进入对应列表，筛选后的记录可以导出CSV。”点租户Token条形图展示用量，再切账单查看已有出账记录。

**收尾，约30秒：**“这一版用于确认展示效果、业务流程和管理字段。设备代理、真实推理执行、自动容灾等是后续接入范围；本轮请重点反馈页面信息是否清楚、操作是否顺手、需要展示哪些业务场景。”

培训时常见问答：曲线是模拟遥测，不代表真实设备采集；地图标准城市为示意，可后台修改；没有自动周期调度、无损checkpoint或真实支付；节点离线告警目前需要人工处置。遇到这些问题按当前实现解释，不把产品规划当作已交付功能。

## 操作与数值核对

2.2可先按F11展示总览7图，悬停趋势查看同一时刻三项利用率；点击GPU型号或任务状态筛选关联列表。紫色小点代表分布在客户城市的边缘设备，点击可定位单台；“查看边缘设备”进入资源监控。后台维护中编辑边缘设备的城市、示意坐标及归属租户并应用，地图与地域统计会同步。进入计量计费点击租户Token条形图，直接打开该租户用量；账款图对应账单。以上图表均从本地模拟业务记录汇总。

精确数值验收先在后台恢复出厂内容，再暂停业务时钟。各主场景独立从标准基线执行；“重置本轮”会保留品牌。

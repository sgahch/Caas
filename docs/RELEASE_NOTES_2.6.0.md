# CaaS 2.6.0 交付说明

2026-10-23。

新增「算力租赁数据」独立页面，按日、周、月、年展示累计租金；总览加入租金卡片与趋势。提供实时累计曲线、分时柱状图、周期累计曲线、小时租金及布林带、产品/机房/租户贡献、收款分布共八张租金图表，合同明细可导出 CSV。

增加四款产品：StarHero X1 边缘设备仅本地产 Token；SLX-V4 Pro 造元为一张 RTX 4090 裸金属；TITANPOWER-X8 擎能和 MOQING-X9 魔擎均为八张 RTX 5090 整机。未提供的新报价显示「待报价」，设置报价并具有匹配硬件后才允许创建租赁订单。已有硬件容量及历史订单保留。

Token 区增加国内与海外模型用量排行、提供方占比及计量明细，支持当日与累计切换。用量源于本地模拟计量，未接入第三方实时排名，模型名称不代表客户或合作关系。

租金按合同分段价量和实际生效时长连续累计；账单维持原有按天进位结算，累计、合同与实收分别展示。年末预计仅包含已签合同有效期限。业务暂停和维护时，新图表及计量同步停止。详细口径与后台操作见「租赁与模型用量说明」。

使用前正常退出旧版，再启动便携版或安装新版。沿用 `%APPDATA%\CaaSDesktop` 的本地数据库、管理员账号和配置；首次补充产品与模型元数据前自动备份。也支持旧内容包导入。

验证环境为本机 Windows 11 x64。单元/服务测试、真实 Electron 交互、历史内容包、实际 EXE 与交叉单实例结果见随包 evidence；物理断网干净机、Windows 10、真实系统多档 DPI 与跨电脑测试范围沿用目标环境验证说明。程序未签名。

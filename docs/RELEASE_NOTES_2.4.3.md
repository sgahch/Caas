# CaaS 2.4.3 交付说明

发布日期：2026-10-21。交付范围：Windows x64 离线桌面展示与本地内容管理平台。

本版本修复旧内容包与旧备份恢复的兼容问题，覆盖运行数据、基线和草稿。原始摘要先校验，再转换旧版策略及遥测等值；容量、引用与账单规则继续校验，导入不迁移账号密码。

应用界面、快照与内容包版本统一；更新回归脚本与使用说明；安装版、便携版从同一批最终构建整理并进行校验。保留 2.4.2 的界面文案和功能布局。

交付内容包括安装版、便携版、标准内容包、源码与锁文件、快速开始、使用说明、演示步骤、数据格式、素材许可、验收证据和 SHA-256 清单。

旧版升级前建议导出一份内容包，退出旧客户端后再打开新版。已有品牌、账号与数据目录继续使用；首次新用户自行设置密码。

计算、设备、遥测与计费仍在本地模拟，本版不包含真实节点代理、远程执行、真实支付或服务端多用户。界面文案调整不改变这一范围。程序未签名，实际环境覆盖情况见《实际测试记录》。
